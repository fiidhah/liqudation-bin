Project Background & Purpose
Project Overview & Key Objectives
Slide 02 / 10

📌 Project Overview & Domain Context

  • The Liquidation Retail Model: Retailers sell customer returns, overstocks, and clearance pallets with progressive daily price cuts.
  • The Reverse Logistics Bottleneck: Billions of returned items sit idle in warehouses due to lack of structured, digitized cataloging.
  • Physical Bin Store Limitations: Merchandise is traditionally dumped into wooden bins where shoppers rummage blindly without knowing inventory or locations.
  • SmartBin's Digital Solution: A centralized platform indexing stock by bin location (Bin A, B, C), displaying condition grading, and enabling 24/7 web commerce.

🎯 Core Project Objectives

  • Automate Daily Price Curves: Eliminate manual re-labeling via database-driven daily price drop schedules (e.g., Friday $14 ➔ Thursday $1).
  • Inventory & Bin Transparency: Display verified condition grades (Brand New, Open Box, Refurbished, Clearance) and exact shelf coordinates.
  • Role-Based Access Governance: Provide isolated, secure portals for Customers, Store Managers, and Super Administrators using JWT & bcrypt.
  • Frictionless Transaction Pipeline: Full commerce flow including dynamic cart calculation, promo vouchers, and Razorpay checkout.
  • Gamify Customer Retention: Drive repeat customer traffic through automated weekly Lucky Draw raffles and coupon validation.
System Comparison & Motivation
Existing System vs. Proposed System
Slide 03 / 10

❌ Existing System (Traditional Brick & Mortar)

  • No Remote Visibility: Shoppers must travel in person with zero prior insight into which products are in stock.
  • Manual Labor Overhead: Store staff spend hours every evening manually replacing price tags or announcing daily fixed prices.
  • Chaotic & Disorganized: Customers dig through unorganized wooden bins without brand, category, or condition data.
  • Cashier Queues & Errors: Physical bottlenecks during morning rushes, paper invoices, and manual billing discrepancies.
  • Zero Customer Engagement: No automated promo coupon redemption, no digital order history, and no verifiable raffle prize system.

✅ Proposed System (SmartBin Web Platform)

  • 24/7 Digital Access: Customers browse, filter, reserve, and purchase liquidation items anytime from any smartphone or browser.
  • Automated Price Engine: Midnight cron / schedule query automatically recalculates selling prices based on the day of the week.
  • Structured Bin Mapping: Each item indicates its physical bin location (Bin A, B), condition rating, original retail price, and savings.
  • Online Checkout & Tracking: Secure Razorpay payment gateway, automated digital receipts, and real-time shipment status updates.
  • Promotions & Gamification: Built-in promotional coupon engine and automated Lucky Draw raffle boards announcing transparent winners.
Product Highlights & Innovations
Core Features of SmartBin
Slide 04 / 10

📅 Dynamic Daily Price Drop

System dynamically determines today's price according to the weekly schedule (e.g. Fri $14 ➔ Wed $2 ➔ Thu $1). Today's deal calculates in real time at checkout.

📍 Bin & Condition Tagging

Items cataloged with exact physical store bin numbers (Bin A, B, C) and transparent condition grading (Brand New, Open Box, Refurbished, Clearance).

🛡️ Multi-Role Security

Decoupled, authenticated portals for Customer, Store Manager, and Administrator with JWT token validation and salted bcrypt password hashing.

🛒 Smart Cart & Wishlist

Real-time stock validation, persistent wishlist storage, instant quantity adjustments, and dynamic subtotal / discount calculation.

🎁 Promotional Coupon Engine

Admin-managed discount vouchers with code validation, percentage discounts, minimum order requirements, and expiration date checks.

🎲 Automated Lucky Draws

Gamified customer retention system where eligible buyers enter draws and winners are announced automatically on a public transparency leaderboard.

Module Description & Role Breakdown

👤 Customer Portal (Storefront)

  • Authentication & Profile: Secure registration, login, and address management via JWT.
  • Dynamic Catalog: Real-time filtering by Category, Brand, Bin Number, and Condition Grade.
  • Shopping Cart & Wishlist: Subtotal calculation, stock checks, and saved favorites.
  • Coupon Engine: Validation of promotional codes with instant percentage deductions.
  • Order Tracking: Live status tracking (Pending ➔ Confirmed ➔ Shipped ➔ Delivered).
  • Lucky Draw Portal: Live view of ongoing draws and announced winners.

🏢 Store Manager Portal

  • Product CRUD Engine: Create, view, modify, and delete inventory items in real time.
  • Physical Bin Allotment: Assign products to store locations (Bin A, Bin B, Bin C).
  • Stock Auditing: Monitor available unit quantities and manage low-stock thresholds.
  • Order Fulfillment: Review customer delivery details and update dispatch stages.
  • Condition Verification: Tag items as Brand New, Open Box, Refurbished, or Clearance.

👑 Super Admin Dashboard

  • Executive Analytics: Overview of revenue, total users, active managers, and order metrics.
  • Manager Oversight: Onboard, edit credentials, or deactivate store manager accounts.
  • Price Schedule Configurator: Adjust daily price curves across Monday–Sunday.
  • Promotional Campaigns: Create coupon codes, discount %, minimum spends, and expiry.
  • Raffle Draws Administration: Initialize lucky draw contests and execute random winner selection.
Relational Data Modeling
Database Schema & Entity Relationships
Slide 07 / 10

1. Authentication & Role Entities

  • admins: admin_id (PK), full_name, email (Unique), password, role, created_at
  • managers: manager_id (PK), full_name, email (Unique), password, phone, address
  • users: user_id (PK), full_name, email (Unique), password, phone, address, created_at
  • Integrity: Passwords stored as 60-char bcrypt hashes; strict email uniqueness constraints.

2. Inventory & Liquidation Logic

  • products: product_id (PK), manager_id (FK), product_name, category, brand, bin_number, condition_type, original_price, price, quantity, image, is_active
  • daily_price_schedule: schedule_id (PK), day_of_week (0-6), day_name, price, description
  • Integrity: Foreign key to managers with ON DELETE SET NULL; condition as ENUM.

3. Commerce & Transactions

  • cart & wishlist: cart_id / wishlist_id (PK), user_id (FK), product_id (FK), quantity
  • orders: order_id (PK), user_id (FK), total, discount, final_amount, status, shipping
  • order_items: order_item_id (PK), order_id (FK), product_id (FK), quantity, price
  • payments: payment_id (PK), order_id (FK), razorpay_id, status, amount, timestamp

4. Gamification & Retention

  • promotional_offers: offer_id (PK), code (Unique), title, discount_percentage, min_order_amount, start_date, end_date, status
  • lucky_draws: draw_id (PK), draw_name, prize, draw_date, description, status
  • lucky_draw_winners: winner_id (PK), draw_id (FK), user_id (FK), prize_won
Tools & Frameworks
Technology Stack Used

🎨 Frontend Layer

⚙️ Backend Layer

  • Node.js: Fast, non-blocking asynchronous event loop runtime.
  • Express.js: Minimalist RESTful API framework and routing engine.

  • Dotenv: Environment variable security.

🗄️ Database & Security

  • MySQL 8.0: Relational ACID-compliant transactional database engine.
  • mysql2: Connection pooling with native Promise support.
  • JWT: Stateless user token authorization.
  • Bcrypt.js: Cryptographic password hashing (10 salt rounds).
  • Integrity: Cascading foreign keys.

  • Postman: REST API endpoint testing and validation.
